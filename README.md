# 🎡 بوت روليت — Infinity Games

بوت ديسكورد يسوي لعبة "روليت إقصاء" مطابقة للفكرة اللي طلبتها:
- عجلة روليت متحركة (صورة حقيقية تدور) بنفس ستايل الصورة المرجعية.
- انضمام لاعبين بعدد قابل للتعديل (افتراضي 20، تقدر تخليه لين 999).
- تدور العجلة وتوقف عند لاعب، وذا اللاعب يختار (خلال 15 ثانية):
  - **طرد لاعب معيّن** (من قائمة اختيار).
  - **طرد عشوائي**.
  - **الانسحاب** (يطرد نفسه).
  - إذا ما رد بالوقت ⏰ يصير طرد عشوائي تلقائي.
- تتكرر الجولات لين يبقى لاعب وحيد = **الفائز**، ويحصل على نقطة تُحفظ له بشكل دائم.
- **متجر خصائص** (`/متجر`) يشتري فيه اللاعب أغراض بالنقاط (درع حماية، مضاعف نقاط، إعادة تدوير، حصانة، شارة VIP...).
- **نظام حفظ قوي**: كل النقاط والفوزات والمخزون تنحفظ بقاعدة بيانات SQLite حقيقية (`better-sqlite3`) بوضع WAL، يعني حتى لو انطفى السيرفر أو تعطل البوت فجأة، البيانات ما تضيع.

```
└── data/                   # هنا ينحفظ ملف قاعدة البيانات roulette.db تلقائياً
```

## 🚀 التشغيل خطوة بخطوة

### 1) أنشئ تطبيق البوت
1. روح [Discord Developer Portal](https://discord.com/developers/applications) واعمل **New Application**.
2. من تبويب **Bot** فعّل:
   - `SERVER MEMBERS INTENT`
3. من تبويب **OAuth2 → URL Generator** اختر Scopes: `bot`, `applications.commands`
   وPermissions: `Send Messages`, `Embed Links`, `Attach Files`, `Read Message History`, `Use Slash Commands`.
   افتح الرابط الناتج وأضف البوت لسيرفرك.
4. خذ نسخة من **التوكن** (Bot Token) و**Application ID** (Client ID).

### 2) جهّز المشروع
```bash
npm install
cp .env.example .env
```
افتح ملف `.env` وحط فيه التوكن والـ Client ID (ولو تبي تسجيل أوامر سريع بسيرفر تجربة، حط GUILD_ID كذلك).

### 3) سجّل أوامر السلاش
```bash
npm run deploy
```

### 4) شغّل البوت
```bash
npm start
```

## 🎮 الأوامر

| الأمر | الوظيفة |
|---|---|
| `/روليت` | يبدأ لوبي جديد (فيه خيارات: الحد الأقصى، الحد الأدنى، وقت الانضمام بالثواني) |
| `/نقاطي [عضو]` | يعرض رصيدك من النقاط، فوزاتك، وعدد مرات الطرد اللي سويتها |
| `/المتصدرين` | لوحة صدارة أعلى اللاعبين نقاط بالسيرفر |
| `/متجر` | يفتح متجر الخصائص للشراء بالنقاط |
| `/مخزوني` | يعرض الأغراض اللي اشتريتها |

**أزرار اللوبي:** انضمام 🎮 / انسحاب 🚪 / بدء الآن ⏩ (لصاحب اللعبة أو مشرف) / إلغاء ❌

## ⚙️ تخصيص سهل

- **عدد النقاط لكل فوز:** غيّر قيمة `WIN_POINTS` بأول ملف `index.js`.
- **أغراض المتجر:** عدّل مصفوفة `seedItems` بملف `utils/database.js` (تقدر تضيف أي غرض تبيه بالاسم والسعر والوصف).
- **شكل العجلة والألوان:** كل شي بملف `utils/wheel.js` (مصفوفة `COLORS`، الأحجام، الخط...).
- **زيادة الحد الأقصى للاعبين لـ 999:** موجود مسبقاً بخيار `الحد_الاقصى` بأمر `/روليت` (تقدر تحط أي رقم لين 999).

---

## 🗄️ ملاحظات عن الحفظ (الداتابيز)

- الملف الفعلي: `data/roulette.db` (ينشأ تلقائي أول تشغيل).
- يشتغل بوضع **WAL** (Write-Ahead Logging) و**synchronous=FULL** عشان أعلى درجة أمان — حتى لو تعطل البوت أو السيرفر بلحظة الكتابة، البيانات محفوظة.
- **مهم:** خذ نسخة احتياطية من مجلد `data/` بين فترة وفترة (خصوصاً قبل أي تحديث كبير للبوت).
- كل شي مربوط بـ `guild_id` يعني كل سيرفر له نقاطه ومتجره الخاص بشكل منفصل تلقائياً.

---

## 🛠️ استكشاف الأخطاء

- **الأوامر ما تظهر:** انتظر شوي (لو سجلتها Global تاخذ لين ساعة)، أو استخدم `GUILD_ID` بالـ `.env` للتسجيل الفوري بسيرفر تجربة.
- **خطأ Missing Access / Permissions:** تأكد صلاحيات البوت بالروم تسمح بإرسال Embeds وملفات وصور.
- **العجلة ما تطلع:** تأكد إن `@napi-rs/canvas` تثبت صح (`npm install` بدون أخطاء).
